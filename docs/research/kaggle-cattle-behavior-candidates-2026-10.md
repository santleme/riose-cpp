# Kaggle bovine behavior datasets: candidate audit

**Checked:** 2026-10-22. This note ranks real observation datasets for activity recognition and individual behavior research. Kaggle public dataset metadata endpoints and linked primary papers/repositories were inspected; no candidate archives were downloaded.

## Ranked candidates

| Rank | Dataset | What it can support | Limits for Campo Vivo |
|---|---|---|---|
| 1 | [Cow nose ring data set](https://www.kaggle.com/datasets/fandaoerji/cow-nose-ring-data-set) | Strongest small Kaggle-first supervised activity dataset. Card v1 reports CC0, one CSV, seven cows at one farm, 11 days, daytime sampling, 10 Hz tri-axis acceleration, timestamps, animal IDs, and behavior labels. Grouped animal splits are possible. | One facility, seven animals, and only sampled daytime data. The Kaggle card describes five behavior labels, while the paper's evaluated target collapsed behavior into feeding, rumination, and “other”; audit the actual versioned CSV and label mapping before modeling. Kaggle card/file metadata disagree on file size (the direct API reports about 45 MB, while search metadata reports about 8 MB), so pin version and SHA-256 on acquisition. It contains no resource, intake, weather, or treatment covariates: useful for activity recognition, not motivation, action choice, or causality. [Source study](https://www.mdpi.com/2076-2615/14/8/1187). |
| 2 | [CBVD-5 cow behavior video dataset](https://www.kaggle.com/datasets/fandaoerji/cbvd-5cow-behavior-video-dataset) | Kaggle card v11 reports CC0 and roughly 11.6 GB. Video and frame annotations cover standing, lying, feeding/foraging, drinking, and rumination. The paper describes 107 cows, one ranch, seven cameras, 96 hours, 687 clips, and about 27,501 labeled samples. | Vision observations, not agent decisions or internal states. One ranch; published random 70/20/10 sample split is not animal- or farm-independent. A later analysis reports that released annotations do not preserve persistent cow identity or explicit camera-to-video mapping. Card text has older/different collection and annotation totals than the paper; audit versioned files. [Original paper](https://www.nature.com/articles/s41598-024-65953-x); [later split/identity analysis](https://pmc.ncbi.nlm.nih.gov/articles/PMC13359905/). |

Could support activity conditioned on environment and location, and held-out-cow evaluation within this deployment. | One farm/deployment; one day of behavior labels; large archive (Kaggle card ~39 GB; upstream images expand to terabytes). Noncommercial share-alike terms constrain reuse and derived artifacts. Use a small sensor subset first; do not treat the MIT license on the code repository as the data license. [Upstream data guide](https://github.com/neis-lab/mmcows); [HF data card/license](https://huggingface.co/datasets/neis-lab/mmcows). |
| 4 | [Cattle activity monitoring](https://www.kaggle.com/datasets/rajaasim7252/cattle-activity-monitoring) | Kaggle card reports CC BY-NC 4.0 and about 152 MB of labeled YOLO images; useful for object detection or visible posture recognition. | Static image labels do not provide animal-linked time series or resource-choice behavior. No valid temporal agent benchmark. |
| 5 | [Beef Cattle Behavior Data Set](https://www.kaggle.com/datasets/lucyfirst/beef-cattle-behavior-data-set) | Video clips labeled for standing, lying, drinking, feeding, and rumination; potentially useful if a vision-recognition task is needed. | Kaggle license is **Unknown**, card reports about 49 GB, and source description is six animals in one barn/camera. Do not use or redistribute until rights are clarified. |

Another Kaggle image-only mirror, [ConBoCuoi](https://www.kaggle.com/datasets/ngochieung/behavior-and-desease-cattle-datasetcow-conbocuoi), claims multiple farms and MIT, but its described files are images/YOLO labels without persistent animal, time, or farm-group metadata. The claims therefore cannot establish a held-out-farm test.

## Independent validation gap

Every behavior-capable Kaggle candidate above describes one farm, ranch, or deployment. Grouping by animal can prevent window-level leakage for the nose-ring set and potentially MmCows, but it only estimates generalization to another animal in the same management and sensor setting. CBVD-5's random sample split is weaker still, and animal grouping appears unavailable in the released labels. No single current Kaggle candidate supplies replicated, identified herds from separate farms with aligned behavior and environment measurements.

An external site challenge is possible by training on the Kaggle nose-ring data and evaluating once on the [Japanese Black Beef Cow dataset](https://zenodo.org/records/5849025): six cows at Shinshu University, one day, 25 Hz neck accelerometry, and 13 video-labeled behaviors. It is only a small, single-site challenge (not a replicated farm benchmark); breed, sensor placement and sampling rate all shift together. Its license is CC BY-NC-ND 4.0, so keep any use noncommercial and review derivative/model redistribution terms. These data support a cross-site activity-recognition stress test, not a broad claim of farm-level generalization.

The current Nellore trough data records equipment entry/exit events, not observed feeding behavior, water intake, or activity; the UFMS growth cohort supports weight-gain/supplementation analysis but is one site/paddock and is not a behavior cohort. Neither closes the independent-farm behavior gap.

## Recommended next experiment

1. At acquisition, pin the exact Kaggle dataset version and file manifest, calculate SHA-256, audit timestamps, IDs, missingness, class meanings and label continuity against the source paper. Resolve the card/paper class-count mismatch before training.
2. Train an activity classifier only: majority/persistence and tree baselines (Random Forest or ExtraTrees) versus a small temporal CNN/TCN. Split by `cow_num` **before** window extraction, normalization, or augmentation. Tune only inside grouped training folds; report per-cow macro-F1, per-class recall, confusion matrices and uncertainty across the seven outer held-out cows. Do not report random-window accuracy as generalization.
3. Freeze model and preprocessing, then run one predeclared external evaluation on Japanese Black with only a small, documented common-label mapping (for example rumination, feeding/grazing, and broad movement/rest). Report per-cow scores and make no tuning decisions on this set. Flag the label, breed, placement and sampling-frequency shifts; six cows on one day do not support population-level precision.

Even a successful result would validate perception of observed activity, not learned needs, resource recognition, action policy, food/water consumption, causal response to management, or emergent social behavior. A real farm-independent behavior benchmark still needs prospective, linked observations from multiple farms/herds, with animal IDs, repeated time labels, resource/environment covariates and an explicit license.
